# Шаблоны вакансий для `bitrix:news`

## Цель

Добавить в мастер `sporina.easysite` два самостоятельных шаблона компонента
`bitrix:news`:

- `vacancies.1` — техническая адаптация `intec.prom/.../news/vacancies`;
- `vacancies.2` — техническая адаптация `intec.prom/.../news/vacancies.1`.

Внешний вид, структура интерфейса и пользовательское поведение каждого
шаблона должны в точности соответствовать своему исходнику. Адаптация касается
только интеграции с `sporina_easy_site`.

## Границы и размещение

Шаблоны размещаются в:

```
install/wizards/sporina/easy_site/site/templates/sporina_easy_site/components/bitrix/news/vacancies.1/
install/wizards/sporina/easy_site/site/templates/sporina_easy_site/components/bitrix/news/vacancies.2/
```

Каждый каталог содержит необходимые файлы шаблона `bitrix:news`, вложенные
шаблоны `bitrix:news.list` и `bitrix:news.detail`, параметры и русскую
локализацию.

## Архитектура

1. `vacancies.1` воспроизводит простой вариант исходного списка вакансий:
   `news.php` подключает `bitrix:news.list`, а `detail.php` —
   `bitrix:news.detail`.
2. `vacancies.2` воспроизводит вариант с боковым меню разделов, списком и
   детальной страницей. Меню реализуется штатным `bitrix:menu`; оно выводится
   только при включённом параметре и наличии пунктов.
3. Вложенный список выбирается параметром `NEWS_LIST_TEMPLATE`. Значение
   проверяется по белому списку доступных вариантов, как в
   `sporina-column-news-company`; недопустимое значение заменяется вариантом
   по умолчанию.
4. Разметка и CSS повторяют исходные варианты, но CSS-классы и JavaScript-
   селекторы получают пространство имён `sporina-`. Код не использует
   `intec.core`, `intec\core`, `ns-bitrix`, `intec-*` и другие Intec-зависимости.

## Параметры

Набор параметров сохраняет все значения, нужные для списка, деталей, навигации,
сортировки, кэширования, SEO, прав доступа и постраничной навигации. Он не
содержит ни одного параметра, вызова компонента или обработчика, связанного с
формой отклика/отправки: формой, почтовым событием, согласием, CAPTCHA,
идентификатором формы либо AJAX-отправкой.

Параметры, определяющие отображение меню, применяются только в `vacancies.2`.

## Поток данных

Стандартный `bitrix:news` передаёт свои параметры в шаблон. Шаблон формирует
параметры вложенных компонентов из этого набора, добавляя URL-шаблоны из
`$arResult`. Список получает выбранный вариант `NEWS_LIST_TEMPLATE`, детали —
стандартный шаблон вакансии. Ни один шаг не отправляет данные пользователя.

## Обработка ошибок

Если задан недопустимый `NEWS_LIST_TEMPLATE`, используется вариант по
умолчанию. Если инфоблок не содержит элементов или меню — соответствующий
блок не выводится. Все шаблоны защищены проверкой `B_PROLOG_INCLUDED`.

## Проверка

- Синтаксическая проверка PHP всех созданных файлов.
- Поиск, подтверждающий отсутствие Intec-импортов/пространств имён и
  параметров или вызовов формы.
- Сравнение структуры созданных файлов с исходными шаблонами и проверка
  использования механизма выбора `NEWS_LIST_TEMPLATE`.
