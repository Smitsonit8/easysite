# Общая пагинация для list.1

## Цель

Применить существующий общий дизайн постраничной навигации к шаблону `bitrix:news.list/list.1`.

## Решение

- Обёртки верхней и нижней пагинации в `list.1` получают общий класс `sporina-news-company__pager`.
- Сохраняется класс `sporina-news-company-stand__pager`, который определяет отступы конкретного шаблона.
- Общие селекторы из `sporina-news/style.css` начнут оформлять разметку `NAV_STRING`; отдельное дублирование стилей не требуется.

## Проверка

- Статический тест проверяет, что обе обёртки пагинации `list.1` содержат оба класса.
