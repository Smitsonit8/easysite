# Оформление: темы, ширина и логотип

## Цель

Сделать настройки оформления наглядными и точными: выбирать тему по цвету,
отображать фактически сохранённую максимальную ширину и управлять логотипом
сайта через загрузку файла.

## Цветовая тема

Поле `template-color-theme` сохраняет существующие ключи тем, но в панели
отображается специальным видом `theme-swatch`. Каждый ключ представлен
квадратной цветовой плашкой, использующей основной цвет соответствующей темы.
Текущая тема визуально отмечена, а выбор плашки изменяет значение поля и
сохраняется обычным действием «Применить».

## Максимальная ширина

Список `template-width` получает выбранное значение только из
`Settings::getAll()` для текущего сайта. Клиентский код панели не должен
подменять его значением по умолчанию. После открытия панели и после её
асинхронного обновления отображается сохранённое значение: 1200, 1440 или
1920 px.

## Логотип

В категории «Оформление» добавляется поле `template-logo` типа загрузки.
Загруженный файл хранится в Bitrix как файл модуля, а настройка содержит его
ID. Допустимы изображения JPEG, PNG, WebP и SVG; сервер проверяет тип и
загруженный файл до сохранения. Панель показывает миниатюру текущего файла,
кнопку загрузки и кнопку «Вернуть стандартный».

При сбросе логотипа пользовательский файл удаляется из хранилища Bitrix,
настройка очищается, а в шапке снова используется `img/logo.svg`. Пока
пользовательский файл не задан, сайт также использует этот стандартный
логотип.

## Интеграция

`Settings` предоставляет URL выбранного файла с резервным значением
`img/logo.svg`. Файл `site/public/ru/include/logo.php` выводит изображение по
этому URL и служит точкой вывода логотипа для include-областей. Шаблон
`header.php` использует этот же URL в параметре `LOGO_SRC` компонента
`sporina:header`, поэтому логотип одинаков в include-области и шапке. Загрузка
и сброс доступны только администратору и используют текущую проверку сессии
компонента настроек.

## Проверка

- Каждая тема выбирается нажатием на цветную плашку и сохраняется.
- Панель отображает фактически сохранённую ширину после повторного открытия.
- После загрузки допустимого изображения оно показано в панели, include-файле
  `site/public/ru/include/logo.php` и шапке.
- Недопустимый файл не сохраняется и показывает понятную ошибку.
- «Вернуть стандартный» очищает пользовательский логотип и отображает
  `img/logo.svg` в панели и шапке.
