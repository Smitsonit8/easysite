# Настройки мобильной шапки

## Цель

Добавить в раздел «Мобильная версия» панели `sporina:system.settings` управление внешним видом и поведением мобильной шапки, не меняя десктопную версию.

## Настройки

В каталоге `Sporina\EasySite\Settings` объявляются три параметра категории `mobile`:

| Ключ | Тип | Значения | Значение по умолчанию |
| --- | --- | --- | --- |
| `mobile-header-color` | select | `colored`, `white` | `colored` |
| `mobile-header-fixed` | checkbox | `Y`, `N` | `Y` |
| `mobile-header-hide-on-scroll` | checkbox | `Y`, `N` | `N` |

Панель отображает выбор цвета как два радиопункта «Цветная» и «Белая», а два остальных параметра — существующими ползунками. Значения проходят текущую валидацию по белому списку.

## Отображение и поведение

Шаблон мобильной шапки получает классы, соответствующие сохранённым настройкам. На ширинах мобильного брейкпоинта CSS:

- задаёт цветную шапку с текущим цветом темы или белую шапку с контрастными иконками;
- фиксирует шапку только при включённой настройке;
- плавно сдвигает шапку за верхнюю границу при наличии класса скрытия.

Небольшой JavaScript запускается только для фиксированной шапки с включённым скрытием. После короткого порога прокрутки вниз он добавляет класс скрытия; при прокрутке вверх или возврате в начало удаляет его. При открытом мобильном меню скрытие не применяется, чтобы навигация оставалась доступной. Логика не работает на десктопной ширине.

## Совместимость

Значения по умолчанию соответствуют ожидаемому текущему виду: цветная закреплённая шапка без автоскрытия. Существующие сохранённые настройки не требуют миграции: отсутствующие ключи получают значения по умолчанию.

## Проверка

Автотесты проверяют новые ключи, допустимые значения и значения по умолчанию в каталоге настроек, а также наличие элементов «Мобильной версии» в конфигурации панели. Статические проверки подтверждают, что шаблон использует классы настроек и содержит логику скрытия при прокрутке.
