# Заголовок инфоблока в колонках главной страницы

## Цель

Дать редактору единый переключатель показа названия инфоблока для каждого
компонента `bitrix:news` с шаблоном `sporina-column-news-company`.

## Решение

- Добавить в параметры комплексного компонента флажок `SHOW_IBLOCK_TITLE` со
  значением по умолчанию `Y`.
- Передавать этот параметр во вложенный `bitrix:news.list`.
- В шаблонах `.default`, `cards` и `timeline` выводить заголовок из
  `$arResult['NAME']` только при значении `Y`.

## Границы

Изменение не затрагивает настройку расположения колонок, шаблоны вне
`sporina-column-news-company`, кеш или настройки панели сайта.
