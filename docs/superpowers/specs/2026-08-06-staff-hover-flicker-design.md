# Устранение мерцания панели сотрудника

## Причина

В `blocks.1` родительская карточка и выдвижная панель одновременно анимируют `transform`. Поскольку карточка также обрезает содержимое через `overflow: hidden`, браузер может показать шов в нижней границе панели во время перекомпоновки слоёв.

## Решение

- Убрать `transform: translateY(-4px)` из hover- и focus-состояний `.sporina-staff__card`.
- Сохранить плавное изменение `box-shadow` на карточке.
- Оставить без изменений анимацию `.sporina-staff__body`, фото и внутреннего контента.

## Проверка

- Статическая проверка подтверждает, что hover-селектор карточки не содержит `transform`, а анимация панели по `transform` сохранена.
