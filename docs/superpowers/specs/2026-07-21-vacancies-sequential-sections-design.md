# Последовательный вывод разделов вакансий

## Цель

В шаблоне `vacancies.1` выводить разделы вакансий подряд, а не переключать их вкладками.

## Решение

`result_modifier.php` сохраняет текущую группировку элементов в `SPORINA_SECTIONS`. Шаблон `accordion/template.php` убирает навигацию вкладок и выводит для каждой группы заголовок раздела, затем её вакансии. JavaScript оставляет только обработчик раскрытия вакансии.

CSS заменяет скрытие неактивных разделов на последовательное отображение и добавляет оформление заголовка секции. Стили аккордеона вакансий не изменяются.

## Проверка

- Все разделы и их элементы видны на странице в исходном порядке.
- Вакансии продолжают раскрываться по клику.
- Раздел без ID отображается под существующим названием «Вакансии».
