# Управление описанием блока новостей

## Цель

Добавить в шаблон `sporina-news-all-modern` настройку, включающую или отключающую отображение текста из `BLOCK_DESCRIPTION`.

## Решение

Параметр `SHOW_BLOCK_DESCRIPTION` добавляется как флажок с начальным значением `Y`. Он получает русскую и английскую подписи в языковых файлах шаблона.

В `template.php` описание выводится, только когда значение параметра не равно `N` и после обработки `BLOCK_DESCRIPTION` остаётся непустой текст. При отсутствии нового параметра используется значение `Y`.

## Проверка

- При `SHOW_BLOCK_DESCRIPTION=Y` заполненное описание отображается.
- При `SHOW_BLOCK_DESCRIPTION=N` описание отсутствует.
- Структура и остальной вывод блока новостей не изменяются.
