# Настройка кнопки «Еще»

## Цель

Добавить в шаблон компонента `sporina-column-news-company` одну настройку, которая включает или отключает кнопку «Еще» в представлениях `cards` и `timeline`.

## Решение

Параметр `SHOW_MORE_BUTTON` добавляется в `.parameters.php` как флажок в группе «Основные настройки». Его начальное значение — `Y`.

Шаблон `news.php` передаёт значение во вложенный `bitrix:news.list` одновременно с явным `LIST_PAGE_URL`. Шаблоны `cards` и `timeline` показывают блок действий, только если `SHOW_MORE_BUTTON` не равен `N` и URL списка определён.

## Совместимость

Для существующих настроек компонента отсутствие параметра трактуется как `Y`, поэтому кнопка остаётся включённой. Отключение флажка скрывает её в обоих представлениях.

## Проверка

- `SHOW_MORE_BUTTON=Y`: кнопка отображается в `cards` и `timeline`, если есть URL списка.
- `SHOW_MORE_BUTTON=N`: кнопка отсутствует в `cards` и `timeline`.
- PHP-синтаксис всех изменённых файлов корректен.
