# Адаптивное отображение имени сотрудника

## Цель

Показывать имя сотрудника полностью, когда оно переносится на несколько строк в карточке `staff/blocks.1`.

## Решение

- Разделить содержимое панели на всегда видимый блок с должностью и именем и раскрываемый блок с контактами и соцсетями.
- Убрать смещение всей `.sporina-staff__body` на фиксированные `100px`.
- Сворачивать и раскрывать только блок деталей через CSS Grid, сохраняя естественную высоту заголовка.

## Поведение

- Однострочные и многострочные имена полностью видны без hover.
- При hover или keyboard focus контакты и соцсети плавно раскрываются над фотографией.
- На мобильных экранах сохраняется существующее постоянное отображение деталей.

## Проверка

- Статический тест проверяет наличие summary/details-разметки и отсутствие фиксированного смещения тела панели.
