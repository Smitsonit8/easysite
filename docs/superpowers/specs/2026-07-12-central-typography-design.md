# Централизация типографики — дизайн

## Цель

Сделать `style/typography.css` единым источником размеров шрифта, межстрочных интервалов и начертаний для шаблона сайта и его компонентных шаблонов, кроме `sporina:system.settings`.

## Область изменений

Обрабатываются исходные CSS шаблона `sporina_easy_site` и CSS его компонентов. Локальные числовые `font-size`, `line-height` и `font-weight` заменяются ссылками на токены из `typography.css`; при отсутствии подходящего токена он добавляется туда с комментарием о назначении.

`typography.css` подключается в `header.php` после базового `style.css`, чтобы общая типографика была доступна всему сайту и могла переопределять старые размеры.

## Исключения

- `install/components/sporina/system.settings/**`;
- `dist/assets/**` и другие сторонние библиотеки;
- `*.min.css`;
- резервные файлы с суффиксом `_`, включая `style_.css`.

## Правила токенов

- Базовые текстовые размеры используют существующие `--font-size-xs` … `--font-size-lg`.
- Заголовки используют `--font-size-h1` … `--font-size-h6`.
- Уникальные роли компонентов получают семантические токены в `typography.css`, например `--font-size-header-meta` или `--font-size-card-date`, а не новые литеральные значения в CSS компонента.
- Межстрочные интервалы используют существующие `--line-height-*` или именованные компонентные токены при обоснованной необходимости.

## Совместимость

Не изменяются селекторы, отступы, сетки, цвета, изображения или JavaScript. Цель — сохранить назначение каждого текста, заменив источник типографических значений на общий файл.

## Проверка

Автоматические тесты и PHP/CSS linting не создаются и не запускаются по явному требованию пользователя. После изменений выполняется только статическая проверка: отсутствуют числовые `font-size`, `line-height` и `font-weight` в CSS в области работ, кроме определений токенов в `typography.css`.
