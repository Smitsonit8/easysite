# Настройки карты контактов — дизайн

## Цель

Добавить параметры карты страницы контактов в общую панель «Настройки сайта» и сохранить один источник значений.

## Решение

`Sporina\EasySite\Settings::DEFINITIONS` получает категорию «Контакты» с пятью настройками:

- `contacts-map-use`: `Y`;
- `contacts-map-lat`: `51.533338`;
- `contacts-map-lon`: `46.034176`;
- `contacts-map-title`: `Местоположение офиса`;
- `contacts-map-height`: `420`.

Панель строится из этих деклараций. Для полей координат, заголовка и высоты используется текстовый ввод; видимость карты — checkbox. Валидация принимает широту и долготу в допустимом диапазоне координат и высоту карты как положительное целое число.

Страница `public/ru/contacts/index.php` сохраняет параметры компонента как fallback. `Settings` предоставляет проверку наличия сохранённого значения для конкретного ключа. Если параметр карты был сохранён в «Настройках сайта», это значение передаётся компоненту с приоритетом. Поэтому параметры `sporina:contacts` можно редактировать штатным редактором Битрикса до первой настройки соответствующего поля в панели сайта; после сохранения настройка сайта становится источником значения для этого поля. Сброс настроек сайта возвращает использование параметров компонента.

## Редактор Битрикса

В вызове `sporina:system.settings` с `MODE => configure` удаляется `HIDE_ICONS => Y`. Поэтому в режиме правки Битрикс показывает иконку параметров. Вызов с `MODE => render` остаётся скрытым, так как он служебный и не выводит интерфейс.

## Ограничения

- Новые настройки добавляются только в `Settings::DEFINITIONS`.
- Проверки и панель выводятся автоматически из декларации.
- Параметры `sporina:contacts` остаются редактируемыми и служат fallback для каждой настройки карты.
- Автоматические тесты не создаются и не запускаются по явному требованию пользователя.
